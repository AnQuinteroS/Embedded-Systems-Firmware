# Embedded Systems & Firmware Engineering

## Overview
This repository contains C and C++ code written for embedded systems, microcontrollers (like ESP32/STM32), and low-level algorithmic logic. 

As an engineering student transitioning to Computer Science, my background in Electronic Engineering provided me with a rigorous foundation in memory management, bitwise operations, and strict hardware constraints. This translates to writing highly optimized, safe, and deterministic software.

## Repository Structure

### 1. [I2C Sensor Monitor (ESP32)](./01_I2C_Sensor_Monitor/)
A C++ implementation for reading raw register data from environmental sensors via the I2C protocol.
* **Core Concepts:** Bitwise shifting, hardware-software integration, deterministic polling, and data calibration.

### 2. [Finite State Machine (FSM)](./02_Finite_State_Machine/)
A standard C++ simulation of a vending machine using strict state-transition logic.
* **Core Concepts:** `enum class` type safety, event-driven state transitions, and object-oriented encapsulation.
